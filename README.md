# UNESCO Dhaka NFC বিজনেস কার্ড সিস্টেম: সেটআপ গাইড

এই সিস্টেম দুটি ফ্রি সার্ভিস দিয়ে চলে:

- **Firebase (Google):** ডাটাবেজ আর অ্যাডমিন লগইন। স্টাফের তথ্য এখানে থাকে।
- **GitHub Pages:** ওয়েবসাইট হোস্টিং। এখান থেকে কার্ডের পেজ খোলে।

প্রথমবারের সেটআপে প্রায় ৩০–৪০ মিনিট লাগবে। এরপর স্টাফের তথ্য বদলাতে কোনো ফাইল আপলোড করতে হয় না, শুধু অ্যাডমিন প্যানেলে লগইন করে এডিট করলেই সব কার্ডে সাথে সাথে নতুন তথ্য দেখায়।

**ফোল্ডারের ফাইলগুলো:**

| ফাইল | কাজ |
|---|---|
| `index.html` | পুরো ওয়েবসাইট (প্রোফাইল পেজ + অ্যাডমিন প্যানেল) |
| `config.js` | আপনার Firebase প্রজেক্টের তথ্য (ধাপ ৭-এ বসাবেন) |
| `firestore.rules` | ডাটাবেজের নিরাপত্তা নিয়ম (ধাপ ৩-এ বসাবেন) |
| `README.md` | এই গাইড |

## পর্ব ১: Firebase সেটআপ

### ধাপ ১: প্রজেক্ট তৈরি
1. **https://console.firebase.google.com** খুলে Google অ্যাকাউন্ট দিয়ে লগইন করুন।
2. **Create a project** (বা Add project) চাপুন।
3. নাম দিন, যেমন `unesco-dhaka-nfc`, তারপর **Continue**।
4. Google Analytics **বন্ধ** করে দিন, তারপর **Create project**। কাজ শেষ হলে **Continue**।

### ধাপ ২: ডাটাবেজ চালু করা
1. বাঁ পাশের মেনু থেকে **Build → Firestore Database** খুলুন, তারপর **Create database**।
2. Location হিসেবে **asia-south1 (Mumbai)** বেছে নিন (বাংলাদেশের সবচেয়ে কাছে), তারপর **Next**।
3. **Start in production mode** বেছে নিয়ে **Create** চাপুন।

### ধাপ ৩: নিরাপত্তা নিয়ম বসানো ⚠️ জরুরি
1. Firestore Database পেজের উপরে **Rules** ট্যাব খুলুন।
2. সেখানে যা লেখা আছে সব মুছে ফেলুন।
3. `firestore.rules` ফাইলটি Notepad-এ খুলে পুরো লেখা কপি করে এখানে পেস্ট করুন।
4. পেস্ট করা লেখায় `'admin-email@example.com'` খুঁজে সেখানে আপনার অ্যাডমিন ইমেইল বসান, ছোট হাতের অক্ষরে।
   একাধিক অ্যাডমিন থাকলে কমা দিয়ে লিখুন:
   ```
   'karim@example.com',
   'second.admin@example.com'
   ```
5. **Publish** চাপুন।

### ধাপ ৪: অ্যাডমিন লগইন চালু করা
1. **Build → Authentication** খুলে **Get started** চাপুন।
2. **Sign-in method** ট্যাবে **Email/Password** বেছে নিন।
3. প্রথম সুইচ **Enable** করে **Save** চাপুন।

### ধাপ ৫: অ্যাডমিন অ্যাকাউন্ট তৈরি
1. Authentication-এর **Users** ট্যাবে **Add user** চাপুন।
2. ধাপ ৩-এ যে ইমেইল দিয়েছেন সেটি দিন, সাথে একটি শক্ত পাসওয়ার্ড। তারপর **Add user**।

### ধাপ ৬: বাইরের কেউ যেন অ্যাকাউন্ট খুলতে না পারে
1. Authentication-এর **Settings** ট্যাবে **User actions** অংশে যান।
2. **Enable create (sign-up)** থেকে টিক তুলে দিন, তারপর **Save**।
3. একই Settings ট্যাবের **Authorized domains** অংশে **Add domain** চাপুন। সেখানে `আপনার-github-নাম.github.io` লিখুন (পর্ব ২ শেষে আপনার GitHub নাম জানা থাকবে, তখনও যোগ করতে পারেন)।

### ধাপ ৭: Firebase-এর তথ্য config.js-এ বসানো
1. বাঁ পাশে উপরের ⚙️ আইকনে ক্লিক করে **Project settings** খুলুন।
2. নিচে **Your apps** অংশে **`</>`** (Web) আইকনে ক্লিক করুন।
3. App nickname দিন, যেমন `nfc-web`। "Firebase Hosting" টিক দেবেন না। তারপর **Register app**।
4. একটা কোড দেখাবে, যার ভেতরে `const firebaseConfig = { apiKey: "...", ... }` আছে।
5. `config.js` ফাইলটি Notepad-এ খুলুন। প্রতিটি `PASTE_...` লেখার জায়গায় Firebase-এর সংশ্লিষ্ট মান বসান: apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId।
6. ফাইল সেভ করুন।

> ℹ️ `config.js`-এর তথ্য গোপন কিছু নয়। Firebase-এর ওয়েব কনফিগ সবসময় পাবলিক থাকে। ডাটাবেজের আসল নিরাপত্তা আসে ধাপ ৩-এর নিয়ম থেকে।

## পর্ব ২: GitHub Pages-এ প্রকাশ

### ধাপ ৮: GitHub অ্যাকাউন্ট ও রিপোজিটরি
1. **https://github.com**-এ অ্যাকাউন্ট খুলুন বা লগইন করুন।
2. উপরে ডান কোণের **+** চিহ্নে ক্লিক করে **New repository** চাপুন।
3. Repository name দিন `unesco-nfc-card`।
4. **Public** বেছে নিন। GitHub-এর ফ্রি প্ল্যানে Pages চালাতে Public লাগে।
5. **Create repository** চাপুন।

### ধাপ ৯: ফাইল আপলোড
1. নতুন রিপোজিটরির পেজে **uploading an existing file** লিংকে ক্লিক করুন।
2. `index.html`, `config.js`, `firestore.rules` আর `README.md` টেনে এনে ছেড়ে দিন।
3. নিচে **Commit changes** চাপুন।

### ধাপ ১০: ওয়েবসাইট চালু করা
1. রিপোজিটরির **Settings** খুলে বাঁ পাশ থেকে **Pages** বেছে নিন।
2. **Source:** Deploy from a branch।
3. **Branch:** `main`, ফোল্ডার `/ (root)` বেছে নিয়ে **Save** চাপুন।
4. ১–২ মিনিট অপেক্ষা করে পেজটি রিফ্রেশ করুন। উপরে আপনার ওয়েবসাইটের ঠিকানা দেখাবে:
   **`https://আপনার-github-নাম.github.io/unesco-nfc-card/`**

## পর্ব ৩: প্রথমবার চালু করা

### ধাপ ১১: অ্যাডমিন প্যানেলে লগইন
1. আপনার ওয়েবসাইটের ঠিকানার শেষে `#/admin` যোগ করে খুলুন:
   `https://আপনার-github-নাম.github.io/unesco-nfc-card/#/admin`
2. ধাপ ৫-এর ইমেইল আর পাসওয়ার্ড দিয়ে লগইন করুন।
3. **"নমুনা তথ্য দিয়ে শুরু করুন"** চাপুন। ৬ জন নমুনা স্টাফ যোগ হবে।
4. নমুনা স্টাফদের এডিট করে আসল তথ্য বসান, অথবা মুছে দিয়ে নতুন স্টাফ যোগ করুন। Excel থেকে একসাথে আনতে চাইলে **CSV ইমপোর্ট** ব্যবহার করুন।
5. **অফিস সেটিংস** ট্যাবে অফিসের ঠিকানা, ফোন আর ওয়েবসাইটের ঠিকানা যাচাই করে **সেভ** করুন।

### ধাপ ১২: পরীক্ষা
1. স্টাফ তালিকায় 👁️ চিহ্নে ক্লিক করে প্রোফাইল দেখুন।
2. 🔗 চিহ্নে ক্লিক করে লিংক কপি করুন, তারপর নিজের ফোনে খুলে দেখুন।

### ধাপ ১৩: কার্ডে লিংক লেখা
অ্যাডমিন প্যানেলের **"📖 কার্ডে লিংক লেখা"** ট্যাবে ধাপে ধাপে নিয়ম দেওয়া আছে। কার্ড **লক করার আগে** ওয়েবসাইটের ঠিকানা চূড়ান্ত কি না নিশ্চিত হয়ে নিন।

## সাধারণ প্রশ্ন

**স্টাফের তথ্য বদলালে GitHub-এ কিছু আপলোড করতে হবে?**
না। তথ্য Firebase-এ থাকে, তাই অ্যাডমিন প্যানেলে সেভ করলেই সব কার্ডে সাথে সাথে নতুন তথ্য দেখায়। GitHub-এ আপলোড লাগবে শুধু `index.html` ফাইলটিই বদলালে, যেমন নতুন ফিচার যোগ করলে।

**নতুন অ্যাডমিন যোগ করব কীভাবে?**
দুটি কাজ করতে হবে:
1. Firestore Rules-এ তাঁর ইমেইল যোগ করে **Publish** করুন।
2. Authentication → Users-এ তাঁর জন্য **Add user** করুন।

**পাসওয়ার্ড ভুলে গেলে?**
লগইন পেজে "পাসওয়ার্ড ভুলে গেছেন?" চাপুন। ইমেইলে রিসেট লিংক যাবে।

**খরচ কত?**
Firebase-এর ফ্রি প্ল্যান (Spark) যথেষ্ট: দিনে ৫০,০০০ বার ডাটা পড়া যায়, যা কয়েক হাজার স্ক্যানের জন্যও যথেষ্ট। GitHub Pages ফ্রি। কোনো ক্রেডিট কার্ড লাগে না।

**কার্ড হারালে কী করব?**
অ্যাডমিন প্যানেলে ওই স্টাফের ⏻ (পাওয়ার) বোতাম চাপুন। কার্ডটি সাথে সাথে নিষ্ক্রিয় হয়ে যাবে, কোনো তথ্য দেখাবে না। নতুন কার্ডে একই লিংক লিখে দিন।

**"অনুমতি নেই" দেখাচ্ছে?**
লগইন করা ইমেইলটি Firestore Rules-এর অ্যাডমিন তালিকায় হুবহু, ছোট হাতের অক্ষরে আছে কি না দেখুন। তারপর **Publish** করেছেন কি না নিশ্চিত হোন।

**কারা কী দেখতে পারে?**
- **যে কেউ:** শুধু সক্রিয় কার্ডের প্রোফাইল আর অফিসের তথ্য।
- **শুধু অ্যাডমিন:** নিষ্ক্রিয় কার্ডের তথ্য, স্ক্যান রিপোর্ট, আর এডিট করার সুবিধা।
