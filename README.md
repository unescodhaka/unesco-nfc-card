# UNESCO Dhaka NFC বিজনেস কার্ড — সংস্করণ ২

সংস্করণ ২-এ যা নতুন:

- **নিরাপত্তা:**
  - কেউ আর পুরো স্টাফ তালিকা একসাথে নামাতে পারবে না।
  - কোন ঘরে কী তথ্য রাখা যাবে তার যাচাই, আর লিংক বা ছবির ঘরে ক্ষতিকর কোড ঢোকানো বন্ধ।
  - ব্রাউজার-নিরাপত্তা নিয়ম (CSP)।
  - বট ঠেকাতে App Check।
  - অ্যাডমিনের অটো-লগআউট।
  - কে, কখন, কী বদলালো তার রেকর্ড, যা কেউ বদলাতে বা মুছতে পারে না।
- **প্রাইভেসি:**
  - মোবাইল নম্বর লুকানোর অপশন।
  - প্রোফাইলে গোপনীয়তা নোটিশ।
  - টিম ডিরেক্টরিতে শুধু নাম আর পদবি।
- **দ্রুততা:**
  - প্রোফাইল পেজে শুধু দরকারি হালকা কোড লোড হয়।
  - আগে দেখা প্রোফাইল সাথে সাথে খোলে, ইন্টারনেট না থাকলেও।
  - ফন্ট আর ছবি নিজের সাইটেই থাকে।
- **নতুন ফিচার:**
  - অ্যাডমিন প্যানেল থেকে সরাসরি কার্ডে লিংক লেখা ও লক করা (Android + Chrome)।
  - সব কার্ডের ডিজাইন একসাথে PDF করা।
  - মাসিক স্ক্যান রিপোর্ট।
  - কার্ডের ৬টি রং।
  - ফোনের সেটিং অনুযায়ী নিজে থেকে ডার্ক মোড।
  - মোবাইলে সহজে ব্যবহারের মতো অ্যাডমিন প্যানেল।
  - ফোনে অ্যাপের মতো ইনস্টল করা যায় (PWA)।

**অ্যাডমিন প্যানেলের নতুন ঠিকানা:** আপনার ওয়েবসাইটের ঠিকানার শেষে `admin.html` যোগ করুন। যেমন: `https://নাম.github.io/unesco-nfc-card/admin.html`

**আপডেট করার ধাপ:** Claude-এর দেওয়া "সংস্করণ ২ আপডেট গাইড" দেখুন।

**সংক্ষেপে:**
1. নতুন `firestore.rules` Firebase-এ পেস্ট করুন, অ্যাডমিন ইমেইল বসান, তারপর Publish করুন।
2. GitHub-এ পুরোনো config.js রেখে দিন। বাকি সব ফাইল আর `assets` ফোল্ডার আপলোড করুন।
3. App Check চালু করুন, তারপর config.js-এর শেষে এই লাইনটি যোগ করুন: `window.RECAPTCHA_SITE_KEY = "আপনার-site-key";`

**ফাইলগুলো:**

| ফাইল | কাজ |
|---|---|
| `index.html` + `assets/app.js` | প্রোফাইল ও হোম পেজ |
| `admin.html` + `assets/admin.js` | অ্যাডমিন প্যানেল |
| `assets/common.js`, `assets/style.css`, `assets/qr.js` | দুই পেজের সাধারণ কোড, ডিজাইন আর QR |
| `assets/fonts`, `assets/img` | ফন্ট, লোগো আর আইকন |
| `config.js` | Firebase আর reCAPTCHA-র তথ্য (আপনার পুরোনোটাই থাকবে; নতুন ইনস্টলে `config.example.js` থেকে বানান) |
| `firestore.rules` | ডাটাবেজের নিরাপত্তা নিয়ম |
| `sw.js`, `manifest.webmanifest` | অফলাইন ক্যাশ আর অ্যাপের মতো ইনস্টল |
